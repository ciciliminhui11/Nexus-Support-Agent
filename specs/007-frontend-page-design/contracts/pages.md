# 页面契约：页面结构、状态与验收映射

**日期**：2026-08-29 | **特性**：[spec.md](../spec.md)

本契约定义各页面的区块结构、状态与验收映射。实现于 `frontend/src/pages/`，遵守[设计系统契约](design-system.md)与[接口契约](frontend-api.md)。

## 1. 注册 / 登录页（`pages/login/`）

| 区块 | 内容 |
|---|---|
| 登录表单 | 手机号/邮箱 + 密码 + 登录按钮；底部「去注册」入口 |
| 注册表单 | 手机号/邮箱 + 密码 + 确认密码 + 注册按钮；底部「去登录」入口 |
| 页旁区 | 品牌标识 + 系统名称（品牌位） |

**状态与交互**：
- 表单实时校验：必填、格式、密码强度、两次一致，错误内联（FR-008）
- 登录中/注册中按钮加载态；登录失败提示（FR-009）；注册成功进入可登录态
- 登录成功 → 进入问答主界面；携带 `redirect` 时返回目标页（FR-011）

**验收映射**：US1 场景 1–6；SC-001。

## 2. 智能问答主界面（`pages/chat/ChatPage.vue`）

| 区块 | 内容 |
|---|---|
| 会话列表（左侧） | 会话项 + 新建按钮 + 空态引导（US3 复用） |
| 消息区（中） | 消息列表（MessageBubble）、欢迎空态（新会话）、自动滚动 |
| 输入区（底） | 多行输入 + 字数计数 + 发送/停止按钮 + 次数剩余提示 |
| 辅助 | 引用来源折叠区、追问建议（可选）、意图标签（可选） |

**状态与交互**：
- 发送：≤500 字前置拦截 + 计数（FR-016）；发送中禁重复；生成中显示「生成中」+ 停止按钮（FR-013）
- 流式渲染：rAF 节流 + 不完整标记修补；`meta` 来源随流落地；`finish` 定格（FR-013/015）
- 停止：AbortController 中止，保留已生成内容（FR-014）
- 错误：`error` 事件/网络中断友好提示 + 重试，保留已发送问题（FR-019）
- 空会话：欢迎语 + 示例问题引导（FR-018）；次数用尽提示（FR-016）
- 反馈：仅 AI 消息提供赞/踩 + 踩展开文字框（FR-026/027/029，详见 feedback）

**验收映射**：US2 场景 1–8；US4 场景 1–5；SC-002/003/004/007/008。

## 3. 会话列表（`pages/chat/` 内左侧面板）

| 区块 | 内容 |
|---|---|
| 列表 | 标题 + 最后消息预览 + 更新时间，当前会话高亮 |
| 操作 | 新建会话；重命名/删除（确认弹窗，加分项） |

**状态与交互**：列表加载中/空态引导（FR-024）；点击切换加载历史（FR-024/005）；新建即激活空会话（FR-023）。

**验收映射**：US3 场景 1–5；SC-005。

## 4. 知识库管理页（`pages/admin/KnowledgePage.vue`，管理端）

| 区块 | 内容 |
|---|---|
| 侧边导航 | 管理端布局（FR-031），当前项高亮 |
| 列表 | 文档表格：名称/类型/大小/状态/上传时间 + 搜索 + 分页 + 空态（FR-032/037） |
| 上传区 | 文件选择（.txt/.md/.pdf 多选）+ 拖拽上传 + 进度 + 类型/大小前置校验（FR-033） |
| 文档操作 | 重命名、删除（二次确认 + 级联清理提示）、失败重传、详情（FR-034/035/036） |
| 状态标签 | 处理中（加载态）/ 就绪（成功色）/ 失败（错误色 + 原因）（FR-034） |

**状态与交互**：上传中临时项 + 进度；轮询仅存在非终态项时开启；删除即时更新列表；搜索无结果空态；未授权访问被守卫拦截（FR-031）。

**验收映射**：US5 场景 1–7；SC-006。

## 5. 全局路由与守卫（`router/index.tsx`，React Router v7 + 守卫组件）

| 路由 | 守卫 |
|---|---|
| `/login` `/register` | 公开；已登录访问跳主界面 |
| `/chat`（含会话列表） | `requiresAuth`：未登录 → `/login?redirect=/chat` |
| `/admin/knowledge` | `requiresAuth` + `adminOnly`：角色非 admin → 拒绝 |
| `*` | 404 页 |

401 拦截：任一 API 返回 401 → 清登录态 → 跳 `/login` 并提示重新登录（FR-010）。

**验收映射**：US1 场景 5–6；US5 场景 7。
