# 第三方工具安装教程

> 本文档覆盖 002/006 所需第三方工具的安装步骤。所有命令在 `backend/` 目录下执行。
> 环境：Windows 11 + Python 3.14（venv：`backend/.venv`）。

---

## §1 ahocorasick（006 意图识别 · 关键词多模式串匹配）

### 结论先行（2026-08-30 实测）

| 包 | 3.14 / Windows 可用性 | 说明 |
|---|---|---|
| `ahocorasick-ng` | ❌ **无任何可用发行版** | `pip install ahocorasick-ng` 报 `No matching distribution found`，连 sdist 都没有，无法安装 |
| `pyahocorasick` 2.3.1 | ✅ **有 `cp314-cp314-win_amd64` 轮子，实测安装成功** | 同一作者（WojciechMula）维护的上游包，API 与 ahocorasick-ng 完全兼容 |

**推荐：用 `pyahocorasick` 2.3.1**，不是自研替代，而是同 API 的可安装包。二者使用完全一致：

```python
import ahocorasick  # 注意：导入名是 ahocorasick（不带 py 前缀）

A = ahocorasick.Automaton()
A.add_word("退货", "intent:after_sale")
A.make_automaton()
for end_idx, val in A.iter("如何退货？"):
    ...
```

### 安装

```bash
cd backend
.venv/Scripts/pip install pyahocorasick
# 预期输出：Successfully installed pyahocorasick-2.3.1
```

### 验证

```bash
.venv/Scripts/python -c "import ahocorasick; A=ahocorasick.Automaton(); A.add_word('退货','x'); A.make_automaton(); print('ok', list(A.iter('如何退货')))"
```

### 若坚持要 ahocorasick-ng（不推荐）

3.14/Windows 下它没有预编译轮子，只能源码编译：

1. 安装 Microsoft C++ Build Tools（含「使用 C++ 的桌面开发」工作负载）：
   <https://visualstudio.microsoft.com/zh-hans/visual-cpp-build-tools/>
2. 尝试源码安装：`.venv/Scripts/pip install --no-binary :all: ahocorasick-ng`
3. 若 `from versions: none`（当前实测如此），说明该版本未对 3.14 发布源码包，**只能改用 pyahocorasick**。这是包维护侧未跟上 3.14，不是本机问题。

## §2 Redis（002 后台任务 · **已废弃，仅未来扩展回 Celery 时使用**）

> Redis 官方**没有原生 Windows 版本**（官方支持停在 3.2）。Windows 上有三条可行路径，**推荐 Memurai**（Redis 官方认可的 Windows 原生方案，开发者版免费）。
>
> **当前状态（2026-08-31）**：002 后台异步任务已改用 FastAPI `BackgroundTasks` 进程内执行（免 Redis/Celery，见 specs/002-knowledge-base/research.md §1）。**本节在本 Demo 阶段无需安装 Redis。** 仅当未来扩展回 Celery + Redis（跨进程 worker）时才需要，本节保留作该扩展的安装参考。

### 方案 A：Memurai（推荐，原生 Windows 服务）

Memurai 是 Redis 官方 Windows 兼容伙伴，支持 Redis 7.2 API，无需 WSL/Docker。

1. 下载安装包：<https://www.memurai.com/> （选 Developer 版，免费，每 10 天需重启一次服务）
2. 运行 MSI 安装向导，勾选「安装为 Windows 服务」（随系统自启，默认端口 6379）
3. 验证：
   ```bash
   memurai-cli.exe ping    # 返回 PONG 即成功
   ```
4. Python 侧无需任何改动，`redis-py` 连 `localhost:6379` 即可。

### 方案 B：WSL2（跑官方 Linux Redis）

```bash
# PowerShell 管理员
wsl --install                # 装 WSL2 + Ubuntu（装完重启）
wsl sudo apt-get update && wsl sudo apt-get install -y redis-server
wsl sudo service redis-server start
wsl redis-cli ping           # PONG
```

注意：Windows 宿主机访问 WSL 里的 Redis 需在 `redis.conf` 设 `bind 0.0.0.0` 并用 WSL 的 IP；且 Redis 不会随 WSL 开机自启。

### 方案 C：Docker Desktop

```bash
docker run -d --name redis -p 6379:6379 redis:7
docker exec redis redis-cli ping   # PONG
```

### 验证 Celery 能连上 Redis

```bash
cd backend
.venv/Scripts/python -c "import redis; print(redis.Redis().ping())"   # 期望 True
```
