# 业务流程说明

> `docs/` 为项目总体文档；各模块规格见 [`../specs/`](../specs/)。

## 问答完整链路（模块 001 RAG 智能问答）

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户/前端
    participant API as POST /api/chat/stream
    participant AUTH as 鉴权/前置校验
    participant INT as 意图识别<br/>(三层漏斗)
    participant R as 检索层<br/>(retriever.py)
    participant BM as BM25<br/>(bm25.py)
    participant RR as Reranker<br/>(reranker.py)
    participant P as Prompt 组装
    participant LLM as DeepSeek V4 Flash<br/>(OpenAI 兼容 API)
    participant DB as 会话/消息/配额

    U->>API: 提问（session_id + question）
    API->>AUTH: JWT 鉴权
    AUTH-->>U: 401 unauthorized
    AUTH->>AUTH: 长度校验 ≤500
    AUTH-->>U: 400 question_empty / question_too_long
    AUTH->>AUTH: 会话归属校验
    AUTH-->>U: 403 session_forbidden
    AUTH->>DB: 每日配额原子递增<br/>(UPDATE … WHERE count<limit)
    DB-->>AUTH: 已达上限
    AUTH-->>U: 429 quota_exceeded
    AUTH->>DB: 读取最近 N 轮历史（context_turns）
    DB-->>AUTH: 多轮 history
    API->>INT: recognize_with_trace(question)
    INT->>INT: 规则层 → 小模型层 → 大模型兜底<br/>(永不抛异常，失败降级 unknown)
    INT-->>API: intent + handler<br/>(rag_qa / small_talk / complaint / clarify)
    API->>DB: 持久化 user 消息（带意图标签）
    alt 意图短路（闲聊/投诉/澄清）
        API-->>U: SSE: data（模板回复）→ finish<br/>不检索、不调用 LLM
    else rag_qa / 未识别
        API->>R: retrieve(query, candidate_k)
        R->>R: 过滤「就绪」文档 + Query 向量化
        R->>R: 向量路 Chroma 检索 candidate_k<br/>+ 阈值过滤（distance ≤ 1-threshold）
        R->>BM: 全量就绪切片建索引<br/>+ 显著词闸门 + Okapi 打分
        BM-->>R: BM25 top-k
        R->>R: RRF 融合（k=60）→ 候选池(20)
        R->>RR: 精排（可选）
        RR-->>R: 精排分数（缺失/失败回落融合序）
        R-->>API: top-6 命中片段<br/>(doc_name/snippet/text)
        alt 两路皆空
            API-->>U: SSE: data（固定兜底话术）→ finish<br/>不调用 LLM
        else 有命中
            API-->>U: SSE: meta（来源）
            API->>P: System Prompt + 编号片段<br/>+ 历史 + 问题（预算截断）
            P->>LLM: messages
            LLM-->>API: 流式 token（首 token 计时）
            alt LLM 超时/限流/异常 或 空响应
                API->>DB: 持久化错误 ai 消息
                API-->>U: SSE: error<br/>(llm_timeout / llm_rate_limited / llm_error)
            else 正常
                API-->>U: SSE: data×n
                API->>DB: 持久化 ai 消息（reference_source）
                API->>API: 输出后来源校验 postcheck<br/>(幻觉检出 → ok / review)
                API-->>U: SSE: finish（message_id + postcheck）
            end
        end
    end
```

## 知识库上传处理流程（模块 002，为检索提供语料）

```mermaid
flowchart LR
    UP[上传文档] --> VALID[类型/大小校验]
    VALID --> PARSE[文本解析<br/>utf-8-sig → utf-8 → gbk 编码兜底]
    PARSE --> SPLIT[段落感知切分<br/>chunk + overlap]
    SPLIT --> EMB[Embedding 向量化<br/>可插拔后端]
    EMB --> CHROMA[切片写入 Chroma<br/>metadata: doc_id/snippet]
    CHROMA --> READY[文档状态: 就绪]
    READY --> RAG[进入混合检索语料]
    SPLIT -- 中途失败 --> ROLLBACK[回滚已写切片<br/>状态置失败]
```

## 状态流转（模块 001 问答链）

```text
请求到达 → JWT 鉴权 → 入口校验（长度 / 会话归属 / 每日配额）→ 多轮历史
  → 意图识别（规则层 → 小模型层 → 大模型兜底，永不抛异常）
     ├─ 闲聊 / 投诉 / 澄清 → 模板回复短路（不检索、不调用 LLM）
     └─ rag_qa / 未识别 → 混合检索
         ├─ 向量路：Chroma 余弦 → 阈值过滤（distance ≤ 1 - threshold）
         ├─ BM25 路：jieba 分词 → 显著词闸门 → Okapi 打分 → bm25_top_k
         ├─ RRF 融合（k=60）→ 粗筛候选池 candidate_k=20
         ├─ Reranker 精排（可选，缺失/失败回落融合序）→ top_k=6
         ├─ 两路皆空 → 兜底话术（不调用 LLM）
         └─ 有命中 → Prompt 组装 → LLM 流式 → 后校验（幻觉检出）→ SSE finish
             └─ LLM 超时 / 限流 / 异常 或 空响应 → SSE error
```

鉴权失败（401）、长度超限（400）、无权访问会话（403）、配额用尽（429）在入口直接拒绝，不进入生成。
