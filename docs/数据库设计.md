# 数据库设计

> `docs/` 为项目总体文档；各模块规格见 [`../specs/`](../specs/)。
>
> 设计约定：MySQL 8.0 / InnoDB / `utf8mb4_unicode_ci`。模型以
> [models.py](../backend/app/db/models.py)（SQLAlchemy 2.0）为准，
> 生产建表执行 [init.sql](../backend/数据库初始化脚本/init.sql)（含索引与注释），
> 测试可用 `create_all()` 便捷建表。

## 表结构说明

### `user` 用户表（003 鉴权）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| account_identifier | VARCHAR(100) | NOT NULL, UNIQUE `uq_user_identifier` | 账号标识：手机号或邮箱 |
| account_type | ENUM('phone','email') | NOT NULL | 账号类型 |
| password_hash | VARCHAR(255) | NOT NULL | bcrypt 加盐哈希，禁止明文 |
| role | ENUM('user','admin') | NOT NULL, DEFAULT 'user' | 角色 |
| daily_quota | INT | NULL | 用户自定义每日提问限额，NULL 使用全局默认值（`system_config.daily_quota_limit`） |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### `user_quota_daily` 用户每日提问计数（001 递增 / 003 展示）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| user_id | BIGINT | NOT NULL, FK → `user.id` `fk_quota_user` | 用户 |
| stat_date | DATE | NOT NULL | 统计日期 |
| count | INT | NOT NULL, DEFAULT 0 | 当日已用提问次数 |
| — | — | UNIQUE `uq_user_quota_daily` (user_id, stat_date) | 每用户每日一行 |

### `session` 会话表（004）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| user_id | BIGINT | NOT NULL, FK → `user.id` `fk_session_user` | 所属用户 |
| title | VARCHAR(100) | NOT NULL | 会话标题（首条消息自动生成） |
| create_time | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| — | — | KEY `ix_session_user_time` (user_id, create_time) | 按用户按时间倒序查会话 |

### `message` 消息表（004）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| session_id | BIGINT | NOT NULL, FK → `session.id` `fk_message_session` | 所属会话 |
| role | ENUM('user','ai') | NOT NULL | 消息角色 |
| content | TEXT | NOT NULL | 消息正文 |
| reference_source | JSON | NULL | AI 回答引用来源数组 `[{doc_name, snippet}]` |
| intent_label | VARCHAR(50) | NULL | 意图标签（006 识别结果落库，如「产品咨询」） |
| create_time | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| — | — | KEY `ix_message_session_time_id` (session_id, create_time, id) | 按会话拉最近 N 轮历史 |

### `knowledge_doc` 知识库文档元数据（002）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| doc_name | VARCHAR(255) | NOT NULL | 原始文件名（含扩展名） |
| file_path | VARCHAR(500) | NOT NULL | 原始文件存储路径 |
| status | ENUM('处理中','就绪','失败') | NOT NULL, DEFAULT '处理中' | 文档状态；仅「就绪」进入检索语料 |
| fail_msg | VARCHAR(1000) | NULL | 失败原因 |
| upload_time | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 上传时间 |
| — | — | KEY `ix_knowledge_status` (status) | 按状态过滤就绪文档 |
| — | — | KEY `ix_knowledge_upload_time` (upload_time) | 文档列表按时间排序 |

### `parse_task` 文档解析任务（002）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| doc_id | BIGINT | NOT NULL, FK → `knowledge_doc.id` `fk_parsetask_doc`, **ON DELETE CASCADE** | 所属文档 |
| status | ENUM('处理中','成功','失败','已取消') | NOT NULL, DEFAULT '处理中' | 任务状态 |
| create_time | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| finish_time | DATETIME | NULL | 完成时间 |
| fail_msg | VARCHAR(1000) | NULL | 失败原因 |
| — | — | KEY `ix_parsetask_status` (status) | 清扫僵尸任务 |

### `feedback` 用户反馈（005）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| message_id | BIGINT | NOT NULL, FK → `message.id` `fk_feedback_message`（不级联） | 被反馈的消息 |
| user_id | BIGINT | NOT NULL, FK → `user.id` `fk_feedback_user` | 反馈用户 |
| feedback_type | ENUM('like','dislike') | NOT NULL | 点赞 / 点踩 |
| feedback_text | VARCHAR(500) | NULL | 可选文字说明 |
| create_time | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |
| — | — | UNIQUE `uq_feedback_message_user` (message_id, user_id) | 每用户每消息仅一条反馈（可改 type） |

### `trace_event` 链路埋点 span（008）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| trace_id | VARCHAR(64) | NOT NULL | 一次链路的关联 ID |
| trace_type | VARCHAR(20) | NOT NULL | `ingest`=文档入库 / `chat`=问答 |
| stage | VARCHAR(50) | NOT NULL | 阶段名（preflight / intent / retrieve / prompt / llm_stream / postcheck …） |
| seq | INT | NOT NULL | 同 trace 内顺序，meta 行 seq=0 |
| status | VARCHAR(20) | NOT NULL | `ok` / `error` / `skipped` |
| start_at | DATETIME | NOT NULL | span 实际开始时间 |
| duration_ms | INT | NULL | 耗时（毫秒） |
| detail | JSON | NULL | 各阶段指标（question 截断/脱敏，不含密钥） |
| doc_id / session_id / user_id / message_id | BIGINT | NULL | 逻辑关联（不建外键） |
| error | VARCHAR(500) | NULL | 短错误消息 |
| create_time | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 落库时间 |
| — | — | KEY `ix_trace_trace_id` (trace_id) | 按 trace 聚合 |
| — | — | KEY `ix_trace_type_time` (trace_type, create_time) | 按类型按时间查询 |
| — | — | KEY `ix_trace_session` (session_id) | 按会话回查链路 |

### `system_config` 运行时配置（公共）

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| key | VARCHAR(100) | NOT NULL, UNIQUE `uq_system_config_key` | 配置键 |
| value | VARCHAR(500) | NOT NULL | 配置值（DB 中存字符串） |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

未配置的 key 回落 [`app/config.py`](../backend/app/config.py) 默认值，热调无需重启。

## 向量库与 MySQL 的关联

- **向量库**：Chroma（持久化 collection `knowledge_chunks`，`hnsw:space=cosine`），供 002 入库写入与 001 检索共用；Embedding 用云端 bge-m3（SiliconFlow），精排用 `BAAI/bge-reranker-v2-m3`。
- **切片 ID**：确定性生成 `{doc_id}-{chunk_index}`。
- **元数据**：`doc_id`（关联 `knowledge_doc.id`）、`chunk_index`、`snippet`（来源摘要），可选扩展 `source_file / section / heading_path / category / version_date / source_priority`。
- **关联性质**：Chroma 元数据 `doc_id` → MySQL `knowledge_doc.id` 为**逻辑关联**（无外键、无事务）。
- **生命周期**：由 `parse_task` 状态机驱动——解析成功 → 写入切片并置文档「就绪」；失败 → `delete_by_doc_id` 回滚已写切片并置「失败」。
- **检索约束**：仅召回 `knowledge_doc.status='就绪'` 文档的切片（检索前先查就绪 ID 集合，再按 `doc_id IN` 过滤 Chroma）。

## 初始数据

`system_config` 由 [init.sql](../backend/数据库初始化脚本/init.sql) 预置默认值（`ON DUPLICATE KEY UPDATE` 幂等），按模块分组：

| 模块 | 键 |
|---|---|
| 鉴权 | `jwt_expire_hours` / `min_password_length` / `login_fail_threshold` / `login_lock_max_seconds` |
| 配额 | `daily_quota_limit` |
| 会话与消息 | `session_page_size` / `message_page_size` / `message_page_size_max` / `default_session_title` / `session_title_summary_len` |
| 问答 | `context_turns` / `rag_top_k` / `rag_candidate_k` / `rag_bm25_top_k` / `rag_rrf_k` / `rag_similarity_threshold` / `rag_reranker_enabled` / `rag_reranker_model` / `context_max_tokens` / `llm_timeout_seconds` / `llm_first_token_timeout` |
| 知识库 | `max_upload_size_mb` / `chunk_size` / `chunk_overlap` / `parse_timeout_seconds` / `embedding_batch_size` |
| 反馈 | `feedback_max_length` |
| 意图识别 | `intent_high_threshold` / `intent_low_threshold` / `intent_clarify_retry` / `intent_reverse_calibrate` / `intent_model_self_check` |

管理员账号不在此脚本硬编码，由后端启动时按 `.env` 的 `ADMIN_ACCOUNT` 预置（密码哈希在应用内生成）。
